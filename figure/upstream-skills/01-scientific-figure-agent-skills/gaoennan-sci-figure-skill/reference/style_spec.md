# 科研数据图风格规范（顶刊 / 一区SCI / MSSP 风格）

> 适用范围：**数据图**（散点 / 折线 / 柱状 / 热力矩阵 / 谱面场）。流程图、框图、CAD/CFD 示意图另立规范。
> 配套文件：`sci_style.py`（matplotlib 可复用样式 + 调色板）、`templates/plot_templates.py`（每类各 2 张模拟图）。

## 0. 底层语言（"Origin 干净风"）
- **字体**：Times New Roman 衬线；数学变量斜体 `$x$`、`$\lambda$`、`$R^2$`；公式/单位用正体。
- **底色**：纯白，无背景填充（空间定位散点除外）。
- **边框**：四边全框（box），轴线宽 ≈1.2 pt。
- **刻度**：朝内（`direction='in'`），等间隔整数，范围两端留白。
- **网格**：默认**无**；仅"性能多线曲线"用 Excel 式浅灰网格。
- **图例**：置于图内（顶部/角落），细框或无框，字号略小。
- **标注**：关键量**就地标注**——柱顶数值、方框包裹指标（`Domain Distance: 3.364`）、红圈+红箭头点出重点/平均。
- **输出**：PNG/PDF，300 dpi，`bbox_tight`。

## 1. 调色板
| 角色 | 色值 | 用途 |
|---|---|---|
| 蓝 `blue` | `#4472C4` | 实际值/真值/Real（主色）|
| 橙 `orange` | `#ED9A3D` | 预测值（方案 A：蓝●实际 + 橙×预测）|
| 红 `red` | `#E8403A` | 基准虚线/强调；方案 B 的第二条线（蓝+红对）|
| 杏 `apricot` | `#F4C79A` | 柱状图统一柱色（+黑描边）|
| 黑 `black` | `#000000` | 节点、Base 信号、坐标 |
| 象限底 `quad_bg` | `#F4F7E7` | 空间定位散点的淡黄绿背景 |
| 四分类 | 红/蓝/金/青 | t-SNE 等四类聚类 |
| colormap-顺序 | 白→红 `Reds` | 注意力权重热力图 |
| colormap-发散 | `jet` 彩虹 | 3D 曲面 / 时频谱（蓝为低能量底色）|

## 2. 标记 / 线型
- 标记：`●`实际、`×`预测、`▲`实验、`○`仿真、`◆/△/▽/□/◇`方法对比（开口标记）。
- 线型：实线 vs 虚线区分两组（如 with/without、x/y）。
- 1:1 基准线：红色虚线。

## 3. 14 种数据图类型（每类要点）
| # | 类型 | 轴/要素 | 配色要点 |
|---|---|---|---|
| 1 | 空间定位散点 | x,y (mm)，象限 + 角点节点 | 淡黄绿底，蓝●实际/橙×预测/黑●节点 |
| 2 | 回归对角线散点 | Predicted–Actual (mm) | 蓝+橙点 + 红虚线1:1 |
| 3 | 逐样本散点 | Sample index–value | 蓝●实际/橙×预测 |
| 4 | 降维特征散点 | PCA(PC1/PC2,%) 或 t-SNE | PCA：蓝○仿真+红▲实验+方框标注；t-SNE：四色聚类 |
| 5 | 信号波形图 | Amplitude(V)–Time(s) | 黑/红双线 或 蓝Real/红Synthetic |
| 6 | 频谱+峰值标注 | Amplitude–Frequency(Hz) | 蓝线 + 峰值斜体标注 $f_1,2f_1$，2 子图 |
| 7 | 真实vs生成对比 | Amplitude–Frequency | 蓝 Real / 红 Synthetic 叠加，多子图按条件 |
| 8 | 训练收敛曲线 | Loss/Score–Epoch | 蓝/红双线，图内右上图例 |
| 9 | 方法对比折线 | Accuracy(%)–SNR(dB) | 多方法开口标记，"Proposed"金色加粗 |
| 10 | 多线性能曲线 | Value–$x$ | 多线+marker+**网格**，实线/虚线分组 |
| 11 | 柱状对比图 | $R^2$/Accuracy | 统一杏色柱+黑描边+柱顶数值 |
| 12 | 单色权重热力图 | NxN 矩阵 | 白→红 + colorbar + 数值标注 |
| 13 | 时频谱图 | Frequency(Hz)–Time(s) | jet（蓝为底）colormap |
| 14 | 三维曲面图 | Accuracy–$\alpha$–$\beta$ | jet 曲面 + colorbar + 峰值文字箭头 |

## 4. 两种配色方案（同一底层语言下的切换）
- **方案 A（蓝 + 橙）**：热力图用白→红单色顺序；几乎无网格 → 偏定量评估（散点/回归/柱状）。
- **方案 B（蓝 + 红）**：3D/时频/云图用 **jet 彩虹**；性能曲线带网格 → 偏信号 + 训练过程。
