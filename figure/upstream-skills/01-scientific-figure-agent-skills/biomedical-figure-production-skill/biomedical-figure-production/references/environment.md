# Tested environment

The first release was tested on Windows with:

- Python 3.12 in a project-local virtual environment;
- Matplotlib 3.10.9;
- Seaborn 0.13.2;
- SciPy 1.18.0;
- Plotnine 0.15.7;
- cnsplots 0.6.0;
- pandas 2.3.3;
- NumPy 2.4.6;
- R 4.6.1;
- system skills for image generation, Origin-style export guidance, and clinical biostatistical review.

Use `requirements-python-lock.txt` for the full tested Python dependency set. The R setup script installs into a local library; the repository records the principal tested R package versions in `requirements-r-tested.txt`. Treat exact versions as a reproducibility record, not as a requirement to downgrade a working project.
