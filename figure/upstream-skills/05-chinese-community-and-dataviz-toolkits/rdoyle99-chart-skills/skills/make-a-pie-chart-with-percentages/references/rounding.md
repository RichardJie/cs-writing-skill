# Rounding to 100 (largest remainder method)

Values: A 33.4, B 33.3, C 33.3 (sum 100.0).

1. Round each down: 33, 33, 33 (sum 99).
2. Points missing: 100 - 99 = 1.
3. Decimal parts: A .4, B .3, C .3. The largest is A.
4. Give the missing point to A: 34, 33, 33 (sum 100).

Rules:
- Rank by decimal part; ties go to the larger value.
- If the user wants one decimal place, do the same at tenths and total 100.0.
- State in a footnote when labels are rounded: "Percentages rounded to total 100."
