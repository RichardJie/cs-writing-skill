# Import steps

- **PowerPoint:** Insert, Pictures, This Device, pick the PNG or SVG. Right click, Size and Position, lock aspect ratio.
- **Google Slides:** Insert, Image, Upload from computer. SVG is accepted; if it fails, use PNG.
- **Keynote:** drag the file onto the slide, or Insert, Choose.
- **Canva:** Uploads, Upload files, drag onto the page. SVG recolors in some plans; PNG always works.
- **Word / Google Docs:** Insert, Pictures; set wrapping to In line with text and width to the text column.
