# Formats

| Format | Use for | Watch out for |
|---|---|---|
| PNG | Slides, docs, web | Fixed pixels; enlarge and it blurs |
| SVG | Anything that will be resized, web, print | Older Office versions may not take it; convert to PNG then |
| PDF | Print, a one-page document | Not every slide tool inserts PDFs |
| JPEG | Photos only | Compression artifacts around text |

Resolution rule: export at 2x the size it will be shown at.
