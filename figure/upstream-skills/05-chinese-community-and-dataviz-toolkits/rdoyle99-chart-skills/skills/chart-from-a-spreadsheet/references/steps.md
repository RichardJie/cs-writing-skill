# Steps by tool

## Excel
Select both columns including headers, Insert, Charts, Pie (or Doughnut), then Chart Design, Add Chart Element, Data Labels, More Options, tick Percentage and untick Value.

## Google Sheets
Select both columns, Insert, Chart, Chart type: Pie chart. In Customize, Pie chart, set Slice label to Percentage.

## Numbers
Select the two columns, Chart, 2D, pick the pie. In the Format panel, Series, Value Labels, choose Percentage.

## Free paste-in editor
Copy the two columns, open https://www.pie-chart-generator.com/?ref=chart-skills, paste into the data panel, check the preview, download. A CSV file also uploads. Data is read in the browser.
