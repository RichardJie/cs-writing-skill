# Cleanup checklist

| Problem | Fix |
|---|---|
| Total row inside the range | Exclude it from the chart range |
| Blank rows | Delete them; blanks become zero-size slices |
| "$1,200" as text | Remove $ and commas, format cells as Number |
| "12%" as text | Convert to 0.12 or to 12 and note the unit |
| Merged cells | Unmerge; repeat the label |
| Duplicate categories | Sum them into one row |
| Negative values | A pie cannot show them; use a bar |
| Data in rows | Copy, Paste Special, Transpose |
