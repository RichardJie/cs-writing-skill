# Academic Themes

## thesis-defense-blue

深蓝学术风，适合计算机、工程、理学、遥感、自动化等理工科论文答辩。

视觉特点：

- 白底或浅蓝灰底
- 深蓝主色
- 细网格背景
- 清晰卡片和表格
- 稳重的中文衬线标题

## thesis-defense-red

学院红正式风，适合人文社科、管理、教育、政策研究和带有学校视觉识别要求的答辩。

视觉特点：

- 白底暖色调
- 红色顶部强调线
- 正式、端庄、汇报感强
- 适合校徽和学院信息展示

## thesis-defense-minimal

黑白极简风，适合本科毕业设计、课程项目、快速组会汇报。

视觉特点：

- 纯白背景
- 黑灰文本
- 极少装饰
- 内容优先

## thesis-defense-serif

论文纸张风，适合硕博论文、文献综述、学术会议报告和理论研究。

视觉特点：

- 米色纸张背景
- 衬线字体
- 文献感和出版物质感
- 适合文字密度略高的内容

## 主题扩展方式

复制任意主题文件，修改 CSS variables 即可：

```css
:root {
  --bg: #ffffff;
  --surface: #ffffff;
  --text-1: #102033;
  --accent: #1f4e79;
  --font-display: "Noto Serif SC", Georgia, serif;
}
```

保持主题文件只修改 token，减少新增选择器。
