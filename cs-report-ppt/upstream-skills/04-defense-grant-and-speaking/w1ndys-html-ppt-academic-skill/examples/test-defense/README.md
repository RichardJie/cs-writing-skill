# thesis-defense

`thesis-defense` 是论文答辩、开题报告、中期答辩和研究生组会的默认完整模板。

## 适用场景

- 本科毕业设计答辩
- 硕士论文答辩
- 博士论文答辩
- 开题报告
- 中期答辩
- 预答辩
- 学术组会汇报

## 默认结构

1. 封面
2. 目录
3. 研究背景与意义
4. 国内外研究现状与问题
5. 研究目标与技术路线
6. 方法或模型设计
7. 实验设计
8. 结果分析
9. 创新点与贡献
10. 总结与展望
11. 致谢与 Q&A

## 使用建议

- 每页只表达一个核心观点。
- 答辩现场页数建议控制在 `分钟数 × 0.8` 到 `分钟数 × 1.1`。
- 结果页优先使用图表和可视化对比。
- 创新点控制在 2-3 个。
- 每页保留 `<aside class="notes">`，用于答辩讲稿或提示词。

## 可切换主题

- `thesis-defense-blue`
- `thesis-defense-red`
- `thesis-defense-minimal`
- `thesis-defense-serif`
