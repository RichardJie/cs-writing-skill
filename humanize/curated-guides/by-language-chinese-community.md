## 第一部分：中文反翻译腔与欧化语法经典文献（余光中、王力、朱光潜、谢益辉及排版标准）

### 1.1 余光中《怎样改进英式中文？——论中文的常态与变态》原始病象分类与原书例句

- **作者**：余光中（1928–2017）
- **原始出处**：原载香港《明报月刊》1987 年 10 月号；后收录于《从徐霞客到梵谷》（台北：九歌出版社，2006-07-01，ISBN `9574442926`，第 237 页）
- **核验馆藏元数据 URL**：国立中山大学·余光中数位文学馆（馆藏号 `nsysu_yu_lit_com_008`）`https://dayu.lis.nsysu.edu.tw/ProList.php?i=0&t=comment&content=nsysu_yu_lit_com_008`
- **核验全文转载 URL**：`https://liujunyi271828.github.io/chinglish/`

#### （1）总论：中文的“常态”与“恶性西化”
- **原话摘录**：
  > “今日的中文虽因地区不同而互见差异，但共同的趋势都是繁琐与生硬，例如中文本来是说「因此」，现在不少人却爱说「基于这个原因」；本来是说「问题很多」，现在不少人却爱说「有很多问题存在」。对于这种化简为繁、以拙代巧的趋势，有心人如果不及时提出警告，我们的中文势必越变越差，而地道中文原有的那种美德，那种简洁而又灵活的语文生态，也必将面目全非。”
  >
  > “措词简洁、句式灵活、声调铿锵，这些都是中文生命的常态。”
  >
  > “英文没有学好，中文却学坏了，或者可说，带坏了。中文西化，不一定就是毛病。缓慢而适度的西化甚至是难以避免的趋势，高妙的西化更可以截长补短。但是太快太强的西化，破坏了中文的自然生态，就成了恶性西化。”

#### （2）病象一：抽象名词成灾、以名词词组取代短句主词、弱动词（万能动词「作出」「进行」）与伪术语
- **以人/具体名词或短句做主词 vs 英文抽象名词词组做主词（余光中原文对照）**：
  - 西化：`他的收入的减少改变了他的生活方式` → 常态：`他因为收入减少而改变生活方式` / `他收入减少，乃改变生活方式`
  - 西化：`横贯公路的再度坍方，是今日的头条新闻` → 常态：`横贯公路再度坍方，是今日的头条新闻`
  - 西化：`书籍的选购，只好委托你了` → 常态：`选购书籍，只好委托你了`
  - 西化：`他们杯葛这种风俗的继续` → 常态：`他们反对保存这种风俗`
- **弱动词 / 万能动词「作出」「进行」（对应 Jacques Barzun 所谓 *weak verb*、George Orwell 所谓 *verbal false limb*，余光中原文对照）**：
  > “当代的中文也已呈现这种病态，喜欢把简单明了的动词分解成「万能动词＋抽象名词」的片词。目前最流行的万能动词，是「作出」和「进行」，恶势力之大，几乎要吃掉一半的正规动词。”
  - 西化：`本校的校友对社会作出了重大的贡献。` → 常态：`本校的校友对社会贡献很大。`
  - 西化：`昨晚的听众对访问教授作出了十分热烈的反应。` → 常态：`昨晚的听众对访问教授反应十分热烈。`
  - 西化：`我们对国际贸易的问题已经进行了详细的研究。` → 常态：`我们对国际贸易的问题已经详加研究。`
  - 西化：`心理学家在老鼠的身上进行试验。` → 常态：`心理学家用老鼠来做试验`（或：`心理学家用老鼠试验`）
  - 西化：`一架客机失事，造成九十八人死亡` → 常态：`一架客机失事，死了九十八人`
- **伪术语（pseudo-jargon，余光中原文对照）**：
  - 西化：`具有很高的知名度` → 常态：`很有名` / `名气`
  - 西化：`这本传记的可读性颇高` → 常态：`这本传记很动人` / `这本传记引人入胜` / `这本传记很好看`
  - 西化：`岂不比一篇急躁的实验小说更具可看性？` → 常态：`岂不比一篇……更耐看（更动人）？`
  - 西化：`更具前瞻性` → 常态：`更有远见`
  - 西化：`富于爱国主义的精神` → 常态：`富于爱国精神`
  - 西化：`这是难度很高的技巧` / `热情型的人` / `太专业性的字眼` → 常态：`很难的` / `热情的人` / `太专门的字眼`

#### （3）病象二：复数词尾「们」与「……之一」「作为……之一的」「最……之一」的泛滥
- **「人们」与「众、们」叠床架屋（余光中原文）**：
  > “不少国人惑于西化的意识，常爱这么添足，于是「人们」取代原有的「人人」、「大家」、「大众」、「众人」、「世人」。「人们」实在是丑陃的西化词，林语堂绝不使用，希望大家也不要使用。电视上也有人说「民众们」、「听众们」、「球员们」，实在累赘。尤其「众、们」并用，已经不通。”
- **「……之一」与「作为……之一的」（余光中原文对照）**：
  - 恶性西化：`作为竹林七贤之一的刘伶以嗜酒闻名`（余光中评：“不但「作为」二字纯然多余，「之一的」也文白夹杂，读来破碎，把主词「刘伶」压在底下，更是扭捏作态”）→ 常态：`刘伶是竹林七贤之一，以嗜酒闻名` / `刘伶列于竹林七贤` / `刘伶跻身竹林七贤`
  - 画蛇添足：`红楼梦是中国文学的名著之一。` / `李广乃汉朝名将之一。`（删去蛇足「之一」）
  - 港式怪句：`我是听王家的兄弟其中之一说的` / `戴维连一直以来都是我最喜欢的导演其中之一`
  - 迂回含糊：`他是当代最伟大的思想家之一` / `他是最有名气的人物之一` → 常态：`他是一个大名人` / `他是赫赫有名的人物`

#### （4）病象三：连接词「和、与、及、以及」在 `and` 意识教唆下挤占并列与「而」字
- **余光中原文摘录与对照**：
  > “中国人绝不说「开门七件事，柴、米、油、盐、酱、醋以及茶。」……目前的不良趋势，是原来不用连接词的地方，在 and 意识的教唆下，都装上了连接词；而所谓连接词都由「和」、「与」、「及」、「以及」包办，可是灵活而宛转的「而」、「并」、「而且」等词，几乎要绝迹了。”
  - 西化：`起步更早及迈步更快` / `慢及可靠` / `缓慢与有把握` → 常态：用「而」（如 `慢而可靠`、`缓慢而有把握`，兼有 `and` 与 `but` 之功用）或直接四字并列（`更为深广更具实质`）。

#### （5）病象四：介词「有关、关于、由于……使得……」的滥用
- **余光中原文对照**：
  - 冗余介词：`欢迎王教授今天来到我们的中间，在有关环境污染的各种问题上，为我们作一次学术性的演讲。`（「中间」「有关」纯属画蛇添足）；`有关文革的种种`、`讨论有关台湾交通的问题`、`关于他的申请，你看过了没有？`、`关于一个河堤孩子的成长故事`（「有关」「关于」完全多余）。
  - 因果冗词（中文重意合，如「清风徐来，水波不兴」无须硬套「因为……所以……」）：
    - 西化：`由于秦末天下大乱，（所以）群雄四起。` → 常态：删掉「由于」与「所以」（`秦末天下大乱，群雄四起。`）
    - 西化：`由于好奇心的驱使，我向窗内看了一眼。` → 常态：`出于好奇，我向窗内看了一眼` / `为了好奇，我向窗内看了一眼`
    - 西化病句：`由于他的家境贫穷，使得他只好休学。` → 常态：`他家境贫穷，只好休学`

#### （6）病象五：副词词尾「……地」与饶舌副词「成功地」
- **余光中原文对照**：
  - `他苦心孤诣地想出一套好办法来。` / `老师苦口婆心地劝了他半天。` / `他知其不可为而为之地还是去赴了约` → 删去「地」，代之以逗点，摆脱呆板主从关系，使句法松动自然。
  - 饶舌副词：`国父孙中山先生成功地推翻了满清。` / `成功地发明了相对论` / `成功地泳渡了直布罗陀海峡`（既然推翻/发明/泳渡就是成功了，「成功地」毫无意义）。

#### （7）病象六：「的的不休」与「前饰关闭句 vs 后饰开放句」
- **少用「的」字之道（余光中原文对照）**：
  - `参差的斑驳的黑影` → `参差而斑驳的黑影`
  - `弯弯的杨柳的稀疏的倩影` → `弯弯的杨柳投下稀疏的倩影`
  - `灰暗的凄冷的天空`、`夜色的来袭`、`风雨的将至` → `灰暗而凄冷的天空`、`夜色来袭`、`风雨将至`
  - `白色的鸭` → `白鸭`；`有不洁的颜色的都市的河沟` → `都市的脏河沟`
- **化冗长前饰（关闭句）为自然分段后饰（开放句）（余光中原文对照）**：
  - 西化长前饰：`我见到一个长得像你兄弟说话也有点像他的陌生男人。`
  - 常态后饰：`我见到一个陌生男人，长得像你兄弟，说话也有点像他。`

#### （8）病象七：生硬「被」字被动句取代自然主动句与中文原生受事动词
- **余光中原文对照**：
  - `我不会被你这句话吓倒。` → `你这句话吓不倒我。`
  - `他被怀疑偷东西。` → `他有偷东西的嫌疑。`
  - `他这意见不被人们接受。` → `他这意见大家都不接受。`
  - `他被升为营长。` → `他升为营长。`
  - `他不被准许入学。` → `他未获准入学。`
  - `他被选为议长` → `他当选为议长`；`他被指出许多错误` → `有人指出他许多错误`；`他常被询及该案的真相` → `常有人问起他该案的真相`。
  - 多样化表达而非千篇一律套「被」：中文原生有「受难」「遇害」「挨打」「遭殃」「经人指点」「为世所重」及受事主语主动式（`糖都吃光了`、`稿写了一半`）。

### 1.2 王力《中国现代语法》“欧化语法”论断与朱一凡《溯本求源：“欧化语法”的由来》

- **作者与平台**：朱一凡（上海交通大学外国语学院副教授、翻译与词典学研究中心常务副主任），上海交通大学外国语学院官网（2014-03-18）
- **核验 URL**：`https://sfl.sjtu.edu.cn/En/Data/View/3303`
- **原始文献引述与核心论点**：
  - **王力先生论欧化与翻译同源**（原文引述）：
    > “谈欧化往往同时谈翻译，有时差不多竟把二者混为一谈。这也难怪，本来欧化的来源就是翻译，译品最容易欧化。”
  - **翻译顺词序省力导致的欧化机制**：朱一凡指出，译者遣词造句有两种选择，“一是顺着原文的语序填补上对应的中文词块，遇到中文没有的词随即把西文的词或音译或意译地引了来；二是把原文的意义融会贯通，重新用汉语的方式将其付诸笔端……顺着原文的词序比较地省力”。
  - **钱钟书评硬译腔**（原文引述）：
    > “好些字法、句法简直不像不懂外文的古文家的‘笔达’，却像懂外文而不甚通中文的人的硬译。”
  - **欧化句法的结构表现与语法书规约溯源**：
    - 词的层面大量运用外来“新名词”，句的层面表现为**“句子附加成分复杂化、连用行为名词、构造多重复句”**。
    - 1924 年黎锦熙《新著国语文法》（商务印书馆）比附英文文法建立以句为本位的体系，“从一开始就犯了一个错误，不是从汉语的事实出发，而是以英文语法作了出发点，拿汉语例子尽可能的靠上去”，客观上赋予了欧化文法在现代汉语教材中的合法地位。

### 1.3 朱光潜《谈翻译》文字六义说与江慧敏《朱光潜翻译思想的语言学维度》

- **作者与平台**：江慧敏（原载《天津外国语大学学报》），中国作家网（2013-07-12）
- **核验 URL**：`http://www.chinawriter.com.cn/2013/2013-07-12/167204.html`
- **原始论点摘录**：
  - 朱光潜在《谈翻译》中剖析“信、达、雅”之“信字最不容易办到”的语言学根源，指出死抠字面直译之所以生硬失真，在于文字除最粗浅的**（1）直指或字典意义（indicative or dictionary meaning）**外，还包含**（2）上下文意义（contextual meaning）**、**（3）联想意义（associative meaning）**、**（4）声音美**，以及两种次要意义**（5）历史沿革意义（historic meaning）**与**（6）习惯语意义（idiomatic meaning）**。
  - **抵制俗滥陈腐译词实例**：朱光潜把英文 `romance` 译为“故事”而非“浪漫史”，理由是后者“被俗人滥用，在中文习惯中已失其原义”。

### 1.4 谢益辉（Yihui Xie）论变态中文、欧化倒装、中英混杂词 `work` 与机械硬译

- **作者与平台**：谢益辉（Yihui Xie，统计学家、`knitr` / `bookdown` / `blogdown` 作者），个人博客 `yihui.org`

#### （1）《变态中文》（2019-06-20）
- **核验 URL**：`https://yihui.org/cn/2019/06/obfuscated-chinese/`
- **核心原文观点与实例**：
  - **教材欧化条件句后置倒装**：
    > “我刚上大学时，在高等代数书上生平头一次见到把“如果”放在后半句的情形（类似“A 是幂等矩阵，如果 A * A = A”这样的句子），所以那条定理我看了好几遍都没看懂；我是指语文而不是数学意义上的没看懂。很久以后脑子才转过弯来，原来那是按照英文句子的语序习惯硬译过来的。”
  - **语言的常态首先是“清楚”**：
    > “我觉得语言的常态首先应该是清楚，至于措辞简洁和句式灵活，则属于次要要求。比如余光中批评的“最……之一”句式，本质上就是因为太含糊；如“某人是某领域最厉害的专家之一”，那究竟是有多厉害呢？还有弱动词的使用，也是因为不清楚……说一本书可读性很好，一方面就跟说一个人高度值很大一样蹩脚（直接说一个人很高就完事了），另一方面其实也不清楚，究竟是怎么个可读法，比如是文字浅显易懂，还是情节吸引人。”

#### （2）《中英混杂语之十恶之首：动词 work》（2018-11-28）
- **核验 URL**：`https://yihui.org/cn/2018/11/work/`
- **核心原文观点与改写对照**：
  > “我反对这个词混入中文，主要是因为这个词用英文表达出来通常意思是模糊的，中文则需要你稍微挑选一下用词，让意思更明确。我认为模糊用词会让人的思想也跟着模糊。”
  - 原例 1（二次转译腔）：`这个 rlomax 包不工作吗？还是要做特殊的变形？` → 谢益辉改写：`这个 rlomax 包不行吗？还是要做特殊的变形？`
  - 原例 2：`这微波炉不 work。` → 谢益辉改写：`这微波炉坏了。`

#### （1）第一层：GPT-5.6 与 Claude Opus 4.6 同向显著的 9 条通用中文 AI 味指标（摘自上游 `README.md` §3.1）
1. **欧化构式「不是 A 而是 B」**（最强纯写作信号：GPT $\delta = +0.88$，Opus $\delta = +0.72$）。
2. **用词不敢重复（词汇多样性 `mtld`/`mattr` 偏高）**（GPT $+0.91/+0.75$，Opus $+0.55/+0.55$）：同一段内轮换“优化／增强／提升／提高”，而人类作者会自然重复同一个词。
3. **结构切得太碎**（小节长度方差 $-0.91/-0.75$，小标题密度 $+0.65/+0.83$，小节数中位数 AI 7 节 vs 人类 1 节）：AI 3000–6000 字文章常切 5–9 节（1.3–1.7 个小标题/千字），人类多整篇连写、按自然话题换段。
4. **句长/节奏太均匀**（句长方差 $-0.88/-0.40$）。
5. **前置定语长（欧化）**（$+0.48 / +0.54$）：中心名词前挂载二十余字修饰成分。
6. **结论提示冒号**（总冒号密度人类反而更高 $-0.37/-0.31$，但语义层「核心是：」「残酷的现实是：」类结论提示冒号 AI 为人类的 **2.1 倍**）。
7. **衔接过度顺滑**（语义层 AI 段间明确承接占 98.9% vs 人类 95.2%；段间直接跳转新话题 AI 仅 2.1%［每 50 段一次］ vs 人类 7.2%［每 14 段一次］，AI 高频以「这也解释了为什么……」「从这个角度看……」起段）。
8. **密集并列/枚举**（顿号 $+0.56$、分号 $+0.80$，语义层密集并列 AI 为人类的 **1.45 倍**）。
9. **比喻贴切度差**（比喻标记词密度人类反而高 2.4 倍，但人工层确证 AI 失败模式集中于：硬套宏大意象如“窄门/三根支柱”、直译腔如“钢夹”、混合比喻、三连标题）。

#### （2）第二层：不同模型在中文里方向完全相反的表层指纹（摘自上游 `README.md` §3.2）
- **破折号 `——`**：GPT-5.6 比人类还少（$\delta = -0.54$），而 Claude Opus 4.6 极度密集（$\delta = +0.95$，100% 文章使用）。
- **每小句「的」字密度**：GPT 比人类少（$\delta = -0.75$），Opus 比人类多（$\delta = +0.62$）。
- **分号/顿号与句法绕行（GPT 专属）**：分号 $\delta = +0.80$；单动词短直句少（$\delta = -0.72$，偏爱一句四动词连环）、静态判断句少（$\delta = -0.71$）、主谓距离短（$\delta = -0.62$）、少提问（$\delta = -0.59$）、句长集中在 25–45 字中档（中句多 $+0.81$、长句少 $-0.68$）。
- **焦点后置与活跃暗喻密度（Opus 专属）**：新信息压在句尾、铺垫占前大半句（$\delta = +0.47$）；活跃暗喻密度 2.851（GPT 2.099 $\approx$ 人类 2.066）。

#### （3）第三层：经配对实验证伪或对当代模型已失效的常见刻板印象（摘自上游 `README.md` §3.1 & §3.3）
- **`"首先/其次/总之"` 连接词**：$\delta = +0.02$，对当代主力模型已彻底失效。

### 3.1 宝玉（`@dotey`）《别再用提示词去 AI 味了，方向就是错的》

- **作者与平台**：宝玉（`@dotey`），个人博客「宝玉的分享」（2026-02-14）
- **核验 URL**：`https://baoyu.io/blog/2026-02-14/remove-ai-writing-flavor`
- **核心论点摘录**：
  1. **为什么通用去 AI 味提示词是一场集体幻觉（三条原因）**：
     - 第一，所有人用同一套去 AI 味提示词，产出变成新的同质化（“从 AI 味 1.0 切换到了 AI 味 2.0”）。
     - 第二，提示词是一次性的，换体裁就打回原形，上次改过的不满意之处模型完全不记得。
     - 第三，只说了一堆“不要”，从来没让 AI“尝过你要的那个味道”。
  2. **AI 味的本质**：“AI 在用所有训练数据的平均风格写作。它学过无数人的文字，最后输出一个‘最大公约数’。”
  3. **四步迭代构建个人 Writing Style Skill（「菜谱法」）**：
     - **第一步（尝你的菜）**：投喂 3–5 篇**纯自己原创**的最满意文章，提取初始写作风格 Skill。
     - **第二步（照菜谱做菜并手动逐句改稿）**：“你自己动手，一句一句改成你满意的样子。别在聊天里跟 AI 说‘这里改一下’，那没用。”
     - **第三步（用 `git diff` 或对比 Prompt 提取修改规律回写 Skill）**：如将 AI 写的 `作为一名深耕 AI 领域多年的老兵` 手动改为 `作为一个做了十几年 AI 的人`，从中提取规则：*不用军事化用语，不用“深耕”这种商业黑话，具体年数比“多年”更好*。
     - **第四步（反复做菜调味）**：迭代 5–10 篇后收敛；Skill 文档分为四模块：**角色与读者、风格要点（配正反例）、禁止清单（忌口表，避免过长自相矛盾）、参考资料（术语对照表与范文）**。

### 3.2 踏雪寻仙（`@taxueseek`）《你写的文章？都是 ai 味》

- **作者与平台**：踏雪寻仙（`@taxueseek`，《白描写作》`plainspoken-writing` 作者），少数派（2026-02-24）

- **核心论点与实操分类摘录**：
  1. **定义与检验标准**：
     - **AI 味定义**：“读一篇文章，每个词都认识，连在一起却不知道它在说什么——这就是AI味。三个症状：空洞比喻让句子看起来高级。AI口头禅让段落读起来熟悉。总分总结构让文章看起来完整……AI味的本质：用确定的套话，掩盖不确定的思考。”
     - **改好的人味标准**：“认识他的人说：「对，他就是这么说话的。」不认识他的人说：「背后有个真实的人。」”
  2. **五步把「人」写回去**：
     - 第一步：先自己写糙稿填充真实经历、判断与感受（“你写的那些糙稿，就是这篇文章里唯一属于你的东西”）。
     - 第二步：让 AI 打磨而非重写，严守改稿纪律：**“不加事实，不编细节，不改立场，不改程度，不改语气。「有一定难度」不能变成「根本不行」，「可以考虑」不能变成「强烈建议」。”**
     - 第三步：按阶段切换角色（写时用第一人称**作者**，改时用**编辑**，验时用目标**读者**）。
     - 第四步：用具体语境描述和负面约束（`不要四字成语，不要排比句，不要总结性收尾`）替代空洞的“要自然”。
     - 第五步：给少样本正反对比示例（比讲指令管用十倍）。
  3. **动笔前按稿件五种来源分诊**：① 人写但套话多（移开套话）；② 人写被 AI 润色淡化（找回原稿痕迹）；③ AI 生成人加几句（揪出那几句重写）；④ 纯 AI 生成（放下稿子重问作者真正想说什么）；⑤ 人主动模仿 AI 腔（先沟通再决定改不改）。
  4. **中文常见 AI 味句式库对照**：
     - **GPT 风格**：「我就在这，不躲不藏，稳稳接住你」「不是……而是……」「首先……其次……最后……」、刻意共情、结尾「希望这个想法对你有帮助」。
     - **国产 AI 风格**：「您好！感谢您提出这个问题」「我将从以下几个方面：1.…2.…3.」、过度礼貌、必用序号分点、结尾总结句。
     - **通用通病**：「融入了、结合了、实现了」「这不仅是……更是……」、“了”字滥用、顿号堆砌并列词、引号加破折号强行制造重点、几乎每段都有金句。

     > “我在 Skill 中没有明确禁止使用「不是...而是...」的句式，而是要求 AI 不能使用冒号和破折号。这在一定程度上带来了间接效果，因为 AI 最爱用的几种句式都依赖这两个标点：「不是 A，而是 B」经常写成「A——不是 B」；定义式总结经常写成「关键在于：A 是 B」；解释性展开经常写成「原因在于：……」。禁掉这两个标点后，模型不得不换句式，而这些替代句式往往更口语化。”
  3. **三 Subagent 上下文隔离审稿架构**：初稿后启动三个独立 Subagent（只喂文章正文、隔离主会话背景，防止主 Agent 盲目自信）：**独立审读 subagent**（降级情绪词如将「背后发凉」改为「愣了一下」、破除同构模板）、**事实核查 subagent**、**终审自检 subagent**。
  4. **能力边界**：Skill 实测约能去除 4–5 成重度 AI 味；过度堆砌硬规则会导致内容支离破碎或催生公式化的“新 AI 味”。

## Core Skills:

1.  **敏锐洞察力：** 精准识别 AI 写作的典型模式（如刻板句式、缺乏情感、过渡生硬等）。

3.  **语言重塑力：** 熟练运用丰富的词汇、多样的句式和修辞手法（比喻、拟人、排比等）进行文本润色与重构。
4.  **情感与个性化注入：** 自然地融入情感色彩、个人视角（适当时）和生动细节，提升文章的 **温度感和代入感**。
5.  **逻辑与流畅性优化：** 确保思路清晰，过渡自然，逻辑链条完整顺畅，提升文章的 **可读性和说服力**。

1.  **需求理解：** 首先明确 **原文的核心目的、目标读者群体**是**普通大众**、期望的语调幽默风趣。

3.  **分步精修：**

    * **词语润色：** 替换平淡或生硬的词汇，选用更精准、生动、符合语境的表达。
    * **情感与细节：** 在关键之处补充感官细节、情感描绘或适当的个人化表达（如使用第一人称、加入思考或感受）。

4.  **一致性检查：** 确保优化后的文章在保留原意的基础上，风格统一，信息准确无误。
5.  **整体通读与微调：** 模拟目标读者进行通读，感受节奏与流畅度，进行最后的细微调整，确保 **"人味"十足**。

## Guidelines for Humanization:

1.  **句式灵动：** 告别死板。长短结合，并列、从句、口语化表达交替使用。
2.  **词汇鲜活：** 拒绝模板化。用具体、形象、有温度的词替换中性、抽象、生硬的词。多用动词，少用被动。
3.  **自然过渡：** 抛弃"首先/其次/总之"。使用更隐性、符合思维流的连接方式（如"说到这里"、"另一方面"、"更重要的是"、"回过头来看"等）。
4.  **视角与情感：** 适度引入。根据文体，考虑使用第一人称分享见解或感受，加入适量的感叹、反问，或通过描绘细节引发共鸣。**展示而非说教 (Show, don't tell)**。
5.  **互动感营造：** 拉近距离。可以适当使用设问、直接称呼读者（如"你可能会想……"），邀请读者思考。

## Constraints:
-   **忠于原意：** 核心信息、关键数据不得篡改或遗漏。
-   **风格匹配：** 优化后的风格需符合原文的 **主题、目的和目标受众**。
-   **自然为本：** 避免过度修饰或炫技，追求 **真诚、自然的表达**。
-   **逻辑严谨：** 优化过程不能破坏原文的逻辑结构。

### 5.2 `op7418/Humanizer-zh` Issue #37（`@LIghtJUNction`、`@zhutoubei`、`@catink`）：去 AI 味规则自相矛盾与「编造虚构事实」批判
- **作者与平台**：`@LIghtJUNction` 发起，`@zhutoubei`、`@xiang2020git`、`@catink` 参与讨论，GitHub Issue `op7418/Humanizer-zh#37`（2026-08-22 至 2026-10-23）
- **核验 URL**：`https://github.com/op7418/Humanizer-zh/issues/37`
- **核心社区批判（直接推动 `op7418/Humanizer-zh` 2026-09-23 重写编辑原则）**：
  - **严禁为“变具体”替作者编造事实**：早期示例为了让句子像真人，把泛泛的咖啡馆改成“开了三年、手冲咖啡、老建筑改造”，把学术摘要补成“肺癌早期筛查、2019–2023 年、5000 例病历”——*“这些内容读起来确实更像真人，但它们不是改写，而是在替作者编事实，和 SKILL 要求的‘保留核心信息’相冲突。真实的人会有具体细节，但不会凭空替用户制造来源和经历。”*

  - **清除英文直译残留规则**：如英文版的 `"以 -ing 结尾的肤浅分析"` 与 `"标题中的标题大写（Title Case）"` 在中文语法中无直接对应物，不能为凑整对称条数生搬硬套。

### 5.3 `MrGeDiao/shuorenhua` PR #14（`@oxpxo`）：纵向语域盲区——「旧人类味 / 年代标记词」
- **作者与平台**：`@oxpxo`，GitHub Pull Request `MrGeDiao/shuorenhua#14`（2026-08-31）

  - **一句话判据与防误杀边界**：*“这个词，今天一线干活的人聊天发帖还会不会这么说？不会，就标。”*（若锚定语域本身是怀旧题材、年代小说或复古文风，则整节放行）。
